# Variable GPOS Examples With Parenthesized Locations

These examples demonstrate variable GPOS values in which each parenthesized
designspace location is followed directly by the value or values at that
location, without a separating colon.

- **`positioning.fea`** - One- and four-metric value records, a variable
  anchor, a named location, and the legacy Glyphs/FEAKit location spelling

The grammar validator checks the syntax but does not compile the variation
data or verify that the example locations are within a font's axis ranges.
