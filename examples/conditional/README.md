# Conditional Feature Code Examples

These examples demonstrate the `condition` statement used to build GSUB and
GPOS FeatureVariations.

- **`feature-variations.fea`** - Default code, one-sided ranges, multiple axes,
  and overlapping condition regions
- **`positioning.fea`** - A conditional GPOS rule

The grammar validator recognizes condition syntax but does not compile
FeatureVariations.
