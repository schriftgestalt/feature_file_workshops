# Token Expansion Examples

These examples demonstrate the three source-environment token forms.

- **`values.fea`** - Named values, arithmetic, glyph metrics, and anchor positions
- **`predicates.fea`** - Predicate-generated glyph lists and feature class membership

The grammar validator recognizes the token forms but does not resolve them.
Compiling these files requires a source environment that supplies the named
values and glyph metadata referenced by the examples.
